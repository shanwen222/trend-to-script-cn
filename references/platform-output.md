# 平台输出适配

这些是内容编排约定，不是平台官方审核承诺。平台规则、商业属性和账号状态变化时，以用户当前发布页和最新规则为准。

热点来源平台与发布平台可以不同。跨平台改写时保留来源语境，不把“微博热榜”改写成“抖音正在热议”，也不把网页搜索摘要写成平台趋势。

## 抖音

- 第一个口播字即进入钩子，且首个短句须经自然朗读在 3 秒内成立。先让陌生观众感知具体相关性、代价/结果、认知冲突或明确问题，再补背景和“上期视频”等连续性信息。
- 输出时单列 `first_3s_hook`、主要机制、正文兑现位置和朗读检查结果；不通过就重写开头，不能用全文质量分抵消。
- 完稿后朗读一遍：删掉念不顺的书面连接词，允许长短句不均，但不要用故意错字、强塞口头禅或虚构经历制造“人味”。
- 输出发布资产包：封面主标题建议、封面副标题建议、视频标题建议、口播正文、视频简介建议、3—5 个话题标题建议、必要的标签和发布时间建议。视频标题至少给出 2—3 个候选并标出推荐项；话题标题要和正文真实相关，不能把普通关键词伪装成平台热榜话题。
- 避免把热点标题原样搬进正文；人物和事件需要事实依据时保留限定语。

## 小红书

- 输出“封面主标题 + 封面副标题 + 标题候选 + 正文分段 + 视频简介 + 话题标题/标签”。标题突出具体场景或问题，封面主标题只保留一个视觉重点，副标题补充回报或限定条件。
- 标签要和内容真实相关，不用无关热词堆砌。
- 如果有商业合作、产品推荐、外链或联系方式，单独列出披露和导流风险，不以换字、谐音或遮挡规避。

## 微博

- 输出短帖正文、可选话题词、讨论引导和配图/视频建议。
- 热点借势要保留来源语境，避免把未经证实的转述写成结论。
- 适合用一个明确观点或问题收尾，便于评论区讨论。

## 视频号

- 输出较完整的口播正文、封面主标题、封面副标题、视频标题、简介、话题标题和标签。
- 作为短视频发布时，同样执行前三秒硬门槛；较长的解释和账号连续性信息放到首个钩子之后。
- 对新闻、健康、金融和商业表达保留更多限定语和来源说明。

## 生成质量检查

这些检查只保证交付完整与事实一致，不替代发布合规审核：

1. 正文实际字数是否落在用户要求范围。
2. 标题、正文、标签是否围绕同一核心，不是否定式标题党。
3. 平台版本是否只做表达适配，没有改变事实和主张。
4. 来源平台、来源类型和覆盖缺口是否准确披露。
5. 自然化改写是否保留了所有事实、数字和限定语。
6. 短视频首个口播短句是否自然朗读不超过 3 秒，并且无需前情就能成立。

完成上述检查后，再按 [publish-precheck-routing.md](publish-precheck-routing.md) 调用外部完整审核引擎。审核引擎修复稿是最终稿；其后若改动标题、正文、简介或标签，必须重新审核。
