# 热点长尾化

长尾化不是把热点词硬塞进行业，而是把短期注意力转换成热点退潮后仍成立的用户问题。

## 四层拆解

1. **事实锁**：记录热点中不可改写的对象、事件、时间、数字、出处和不确定项。
2. **热点内核**：提炼它正在激活的情绪、选择、矛盾或认知变化。
3. **常青张力**：找到目标行业长期存在、且与内核同构的问题。
4. **行业桥接**：解释两者为何相关，并给观众一个行业内可用的判断或方法。

推荐表达：

`热点事实 → 为什么大家在意 → 行业中的同类问题 → 可复用判断/方法`

## 通过条件

- 删除热点专有名词后，核心问题仍值得目标人群看。
- 换成另一个相似事件时，行业解释依然成立。
- 行业桥接能用一句因果或类比关系说明，不靠谐音、关键词重合或强行蹭热度。
- 热点只提供入口，正文主要篇幅用于行业价值。
- 标出时间敏感内容；过期后可以删除或替换，不破坏主体。

## 失败模式

- 标题谈热点，正文突然推产品。
- 只复述新闻，没有行业增量。
- 用单个关键词制造虚假关联。
- 把争议当结论，省略事实边界。
- 为长尾而抽象到没有具体场景。
