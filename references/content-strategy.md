# 内容心理策略

本模块是写作决策层，不是“爆款公式”或心理学术语展示层。它帮助选择表达顺序、证据和观众回报，不承诺流量结果。

## 总原则

- 先确定真实材料和观众回报，再选择心理机制。
- 每条内容只选择能被素材支撑的机制；机制用于导演写作，不直接写进成稿。
- 信任、回报与事实完整性是硬约束，不能为制造冲突而牺牲。
- 默认内部生成 3 个钩子。短视频候选先过“前三秒硬门槛”，再按“回报兑现度 → 可信度 → 注意力”排序，选中一个。
- 30–60 秒正文通常使用 2–4 个主要机制；更长内容可增加，但每个机制必须有明确功能。
- 下列评分是编辑启发式，不是平台流量预测模型。

## 输入判定

在动笔前确定：

1. 内容类型：科普、共鸣、观点、故事、教程、案例、商业转化。
2. 目标观众：当前处境、已有认知、最想解决的具体问题。
3. 真实材料：用户事实、可追溯外部事实、允许创作的表达。
4. 观众回报：看完后获得的判断、方法、解释、行动或情绪价值。
5. 内容目标：停留、理解、收藏、讨论、关注、咨询或转化。

材料真实性分级：

- A：用户提供或可核验的一手事实。
- B：有来源、日期与边界的外部事实。
- C：创作性类比、观点或表达。不得伪装为 A/B 级事实。

## A-R-C-T-P-S 决策框架

不是每项都要同等用力，但 T、P 和事实完整性必须过线。

| 维度 | 写作问题 | 可用方法 | 禁区 |
|---|---|---|---|
| A Attention | 为什么此刻停下来？ | 具体异常、信息缺口、结果前置、场景切入 | 空泛震惊、延迟兑现 |
| R Relevance | 为什么与我有关？ | 身份、行为、处境、内心冲突 | 擅自诊断人格或疾病 |
| C Conflict | 什么张力推动观看？ | 认知反差、目标与现实、短期与长期、表象与机制 | 虚构敌人、夸大危机 |
| T Trust | 为什么相信？ | 可核验事实、具体细节、机制解释、适用边界 | 编数字、冒充权威、绝对化 |
| P Payoff | 看完具体得到什么？ | 命名、重构、步骤、判断标准、新问题 | 只有情绪和金句 |
| S Social | 为什么愿意转发或评论？ | 身份表达、帮助他人、可讨论判断、共同经历 | 煽动对立、强迫互动 |

常见侧重：

- 科普：A + C + T + P
- 共鸣：R + C + P + S
- 观点：A + C + T + S
- 教程：R + T + P
- 故事：A + R + C + P
- 商业转化：R + T + P；商业意图透明

## 钩子候选

内部生成 A/B/C 三个方向，最终只保留一个：

- A：具体结果或代价前置。
- B：反常识或认知冲突，但必须紧跟依据。
- C：高相关场景或身份镜像。

### 短视频前三秒硬门槛

适用于抖音、微信视频号及用户明确要求的其他短视频口播。前三秒钩子与完整开场不是一回事：前三秒只负责让目标观众愿意继续听，随后 5–10 秒再补充承诺、范围或必要背景。

- 钩子必须从第一个口播字开始，不能先问候、自我介绍、复述标题、感谢观众、交代“上期视频”或铺陈时代背景。
- 首个短句必须让陌生观众至少感知一项：与自己的具体关系、正在付出的代价、可验证的异常/结果、认知冲突，或一个明确且不能立刻自行回答的问题。
- “上期我答应过”“今天教大家”“这期全是干货”“看到最后”等只说明视频安排，本身不算前三秒钩子；如需保留，放到钩子后。
- 文本阶段把首个口播短句作为前三秒代理，优先控制在约 18 个汉字以内；中英文、数字和停顿会改变时长，完稿后必须自然朗读计时，超过 3 秒就压缩。
- 不以音量、夸张词或无关悬念代替信息。删除“震惊、一定、秘密”等词后，钩子仍应成立。
- 前三秒提出的代价、结果或问题必须在正文中明确兑现。不能用一个热门矛盾吸引人，再转去讲另一件事。

短视频候选出现以下任一情况，直接淘汰：

1. 前三秒可以整段删掉，而不影响观众理解后文。
2. 只有主题，没有说明为什么与观众有关，例如“今天聊聊选题工作流”。
3. 只对看过上一期的人有效，陌生观众无法理解。
4. 朗读三秒后仍未出现具体对象、冲突、代价、结果或问题。
5. 依赖虚假数字、绝对承诺、恐惧放大或正文无法兑现的信息缺口。

逐个检查：

1. 短视频首个短句能否在自然朗读 3 秒内成立？
2. 前 1–2 句是否明确承诺了什么？
3. 正文是否真的兑现同一承诺？
4. 删除夸张词后是否仍然成立？
5. 是否依赖无来源的数字、权威或结论？
6. 是否适配目标平台的阅读/观看入口？

信息缺口必须尽快关闭；不能用“最后告诉你”拖延一个本可立即说明的答案。

## 结构选择

根据内容目标选择一种主结构，不机械拼接：

1. 异常 → 解释 → 判断标准
2. 场景 → 冲突 → 重构 → 行动
3. 误区 → 原因 → 方法
4. 结果 → 过程 → 可复用原则
5. 问题 → 三步方案 → 边界
6. 故事 → 转折 → 洞察
7. 两种选择 → 对比 → 决策标准
8. 观点 → 证据 → 反方边界 → 结论

## 信任与回报硬检查

- 每个事实性主张均有来源或被明确降级为观点。
- 反常识结论附近出现证据、机制或适用边界。
- 医疗、金融、法律等高风险主题不把一般信息包装为个体建议。
- 删除情绪词和金句后，正文仍留下至少一个可复述的判断、方法或解释。
- “不是 A，而是 B”全篇默认最多一次；不需要金句时不要硬造。

## 内部评分

每项 0–10：Hook、Relevance、Tension、Trust、Payoff、Naturalness、Shareability、Integrity。

出现以下任一情况必须改写：

- 短视频 `First3sHook` 未通过，或 Hook < 8
- Trust < 6
- Payoff < 7
- Naturalness < 7
- Integrity < 8
- 平均分 < 7.5

`strategy_mode=debug` 时输出候选钩子、每个候选的前三秒原文与淘汰结果、机制选择、结构、证据位置、评分及改写理由；其他模式只输出必要结论。短视频最终稿始终保留 `first_3s_hook` 检查结果。

## 研究边界

框架参考了信息缺口、自我参照、叙事沉浸和高唤醒情绪传播等研究方向，但从实验结论到具体平台文案效果存在外推边界。不得把这些机制写成“必火”“操控用户”或确定性因果承诺。

- Emotion and virality: https://doi.org/10.1509/jmr.10.0353
